# Gym Lover's Cafe Website

A modern landing site for Gym Lover's Cafe, designed to showcase healthy meals, promote online ordering, and convert visitors with clear calls to action.

## Features

- Responsive design for mobile, tablet, and desktop
- Clean product/order modal interactions
- Fresh branding with green accent palette
- Fast performance using Next.js and Tailwind CSS

## Local Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build

```bash
npm run build
npm start
```

## Notes

- Uses Next.js 14 and Tailwind CSS 3
- Includes a modern order modal and hero section styles
- Ideal for small cafe or meal delivery landing pages
